# MERIDIAN Community Code of Conduct

As contributors and maintainers of MERIDIAN, we commit to fostering an open, welcoming, diverse, inclusive, and healthy community.

## Standards
- Demonstrate empathy and kindness toward other participants.
- Respect diverse viewpoints and constructive technical critiques.
- Focus on technical merit, empirical benchmark data, and code quality.
- Maintain professional communication across discussions, issues, and code reviews.

## Enforcement
Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainers. Maintainers have the right to remove or edit comments, commits, and pull requests that do not align with these standards.
