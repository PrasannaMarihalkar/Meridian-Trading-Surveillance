# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MERIDIAN:

1. **Do not create a public GitHub issue.**
2. Send a report directly to the repository maintainer via GitHub Security Advisories or email.
3. Include the component name (Engine, Backend, Database, Frontend), reproduction steps, and potential exploit impact.
4. Maintainers will review the report and coordinate a patch promptly.
